# Decision Log

This file documents major technical choices that shaped the project.

It should capture not only the decision itself but also the reason behind it, because this repo has had multiple experimental phases and the current state is the result of many trade-offs.

Examples of entries include:

- density-map regression instead of direct count prediction,
- dataset cleanup decisions,
- choices about augmentation and preprocessing,
- seed and split reproducibility decisions,
- removal of failed or unstable experiment directions.
