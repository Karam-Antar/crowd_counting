# MLflow Interpretation

MLflow is not just a metrics store. In this project, it is also a record of the experimental narrative.

When reviewing a run later, always ask:

- what code path was active at that time,
- which dataset assumptions were in place,
- what changed compared with the previous run,
- was this run a reference point, a dead end, or a regression.

This helps preserve the project memory that would otherwise be lost as the codebase evolves.
