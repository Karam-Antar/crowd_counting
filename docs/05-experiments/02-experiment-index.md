# Experiment Index

This project has gone through many MLflow runs and multiple code variants. The experiment index is meant to preserve a high-level map of what was attempted and why.

Use it to distinguish:

- the current best baseline,
- candidate experiments worth revisiting,
- runs that were superseded,
- runs that were exploratory and not worth keeping.

The purpose of this file is not to list every run exhaustively, but to help future engineers navigate the history without guessing.
