# Future Work

This file is a living list of the next logical improvements for the project.

Possible future work may include:

- improving experiment indexing and run annotations,
- formalizing the best-known baseline configuration,
- strengthening the reproducibility story,
- documenting unresolved issues or model limitations,
- turning the current best run into a cleaner canonical reference.

This keeps the project from losing momentum after the initial experimental phase.
