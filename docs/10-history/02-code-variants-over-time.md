# Code Variants Over Time

This project has had multiple implementation variants across different MLflow runs. Some were improvements, some were exploratory, and some were ultimately abandoned.

This document helps distinguish:

- the current stable code path,
- variants that were promising but not retained,
- code changes that affected the data contract,
- runs that should be treated as historical rather than active.

This is especially important in a project with many runs and evolving assumptions.
